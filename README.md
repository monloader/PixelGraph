# Пиксель Граф 🎨

**Пиксель Граф** — это простой и удобный онлайн-редактор пиксельной графики в ярком неоновом стиле.

🚀 **[Открыть редактор в браузере](https://monloader.github.io/PixelGraph/)**

---

## ✨ Что умеет этот проект:
* **Рисование мышкой:** можно зажать левую кнопку мыши и водить по экрану, чтобы быстро закрашивать пиксели.
* **Режим «Радуга»:** при включении этого режима каждый пиксель будет окрашиваться в случайный яркий цвет.
* **Сохранение в PNG:** готовую картинку можно мгновенно скачать на компьютер одной кнопкой.
* **Чистый код:** проект разделен на три аккуратных файла (HTML, CSS, JS) без использования сложных библиотек.

---

## 🛠️ Технологии:
* **HTML5** (разметка холста)
* **CSS3** (неоновые эффекты и сетка)
* **JavaScript** (логика рисования и генерация файла картинки)

---

## 🚀 Как запустить у себя на компьютере:
Полноценно запустить проект с компьютера можно только через локальный сервер (например, расширение **Live Server** в VS Code).
